# auth-rbac Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (chosen) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Under Comet manual-gating: after each task, commit + tick, then STOP for user permission before the next. Code review runs once after ALL tasks (no per-task review).

**Goal:** Turn the CometKit starter's generic auth into tenant-scoped RBAC with two roles (`admin`, `staff`), admin-only user administration, soft deactivation, `waNumber`, an httpOnly-cookie session with server-side route gating, and a disabled-but-present `/register` placeholder.

**Architecture:** Adapt the existing NestJS (Fastify) + passport-jwt auth and the users CRUD worked example rather than rebuilding. Roles derive from one shared `USER_ROLES` tuple. Deactivation is a soft `isActive` flag replacing hard delete, enforced at login and per-request in `jwt.strategy`. The session JWT moves into an httpOnly cookie so Next.js `middleware.ts` can gate `/dashboard/*`; the ky client sends credentials and the API keeps a Bearer-header fallback for existing tests.

**Tech Stack:** TypeScript 6, NestJS + Fastify, passport-jwt, Drizzle ORM (PostgreSQL 17), Zod 4, Next.js (App Router), TanStack Query, ky, Vitest, bun.

## Global Constraints

- **DRY boundaries:** wire shapes (Zod schemas, response interfaces) live in `packages/shared`; persisted columns live in `packages/db`; `USER_ROLES` lives in `packages/shared` and the Drizzle `pgEnum` derives from it. Never redeclare a shape across the boundary. Dependency direction: `shared ← db ← api`, `shared ← web`.
- **Password hashing** only via `apps/api/src/common/password.ts` (`hashPassword`/`verifyPassword`); seed uses `bcryptjs` directly (existing pattern).
- **Errors:** throw Nest `HttpException` subclasses; never `try/catch` to shape errors in controllers. Login failures return the generic 401 "Invalid email or password" — do NOT disclose deactivation.
- **Zod 4 idioms:** `z.email()`, `z.enum(...)`. **Vitest note:** in files run under Vitest, import zod as `import * as z from "zod"` if a named import breaks (`z.object` undefined) — but `packages/shared` already uses `import { z } from "zod"` and builds; keep the existing style there.
- **Route order:** static Nest segments before parameterized (`me` before `:id`; `:id/deactivate` after `me`).
- **New runtime imports must be added to that package's `package.json`** — bun's isolated linker does not hoist. New dep: `@fastify/cookie` in `apps/api`.
- **Commands:** run bun via bash after `export PATH="/c/Users/rahma/.bun/bin:$PATH"`. Quality gate `bun run verify` (typecheck+lint+test); integration `bun run test:int` in `apps/api` (needs local Postgres). Always `bun run db:migrate` before `bun run db:seed`.
- **Role fixtures:** changing `USER_ROLES` breaks existing specs that use `role: "user"`. Every task that touches a file with a `"user"` fixture updates it to `"staff"` (or `"admin"`) in the same task.
- **Cookie names:** httpOnly session = `cometkit_token`; client-readable session hint = `cometkit.authed` (value `"1"`, no token material).

```ts
  async deactivateUser(actor: AuthUser, id: string): Promise<UserDto> {
    if (!canDeactivateUser(actor, id)) {
      throw new ForbiddenException("You cannot deactivate your own account");
    }
    const [row] = await this.db.update(users, { isActive: false }, eq(users.id, id));
    if (!row) throw new NotFoundException("User not found");
    this.logger.info({ userId: id, actorId: actor.id }, "user.deactivated");
    return toUserDto(row as User);
  }

  /** Admin: reactivate a previously deactivated user. */
  async reactivateUser(id: string): Promise<UserDto> {
    const [row] = await this.db.update(users, { isActive: true }, eq(users.id, id));
    if (!row) throw new NotFoundException("User not found");
    this.logger.info({ userId: id }, "user.reactivated");
    return toUserDto(row as User);
  }
```

```ts
import { Body, Controller, Get, HttpCode, Post, Res, UseGuards } from "@nestjs/common";
import type { FastifyReply } from "fastify";
import { loginSchema, type AuthResponse, type AuthUser, type LoginInput } from "@cometkit/shared";
import { ZodValidationPipe } from "../common/zod-validation.pipe";
import { AuthService } from "./auth.service";
import { CurrentUser } from "./current-user.decorator";
import { JwtAuthGuard } from "./jwt-auth.guard";
import { SESSION_COOKIE } from "./session-cookie";

const COOKIE_OPTS = {
  httpOnly: true,
  sameSite: "lax" as const,
  secure: process.env.NODE_ENV === "production",
  path: "/",
};

@Controller("auth")
export class AuthController {
  constructor(private readonly auth: AuthService) {}

  @Post("login")
  @HttpCode(200)
  async login(
    @Body(new ZodValidationPipe(loginSchema)) input: LoginInput,
    @Res({ passthrough: true }) reply: FastifyReply,
  ): Promise<AuthResponse> {
    const result = await this.auth.login(input);
    void reply.setCookie(SESSION_COOKIE, result.tokens.accessToken, COOKIE_OPTS);
    return result;
  }

  @Post("logout")
  @HttpCode(204)
  logout(@Res({ passthrough: true }) reply: FastifyReply): void {
    void reply.clearCookie(SESSION_COOKIE, { path: "/" });
  }

  @Get("me")
  @UseGuards(JwtAuthGuard)
  me(@CurrentUser() user: AuthUser): AuthUser {
    return user;
  }
}
```

```ts
// The real session token lives in an httpOnly cookie set by the API and is NOT
// readable here. This is only a non-sensitive client hint so the UI knows a
// session likely exists (gates the /auth/me query). Server middleware reads the
// httpOnly token cookie directly.
const HINT = "cometkit.authed";

export function hasSession(): boolean {
  if (typeof document === "undefined") return false;
  return document.cookie.split("; ").some((c) => c === `${HINT}=1`);
}

export function setSessionHint(): void {
  document.cookie = `${HINT}=1; path=/; SameSite=Lax`;
}

export function clearSessionHint(): void {
  document.cookie = `${HINT}=; path=/; Max-Age=0; SameSite=Lax`;
}
```

```ts
import { NextResponse, type NextRequest } from "next/server";

const SESSION_COOKIE = "cometkit_token";

export function middleware(request: NextRequest) {
  const hasSession = request.cookies.has(SESSION_COOKIE);
  if (!hasSession) {
    const login = new URL("/login", request.url);
    return NextResponse.redirect(login);
  }
  return NextResponse.next();
}

export const config = {
  matcher: ["/dashboard/:path*"],
};
```
